# Design System — Padrão Digital de Governo (GOV.BR DS)

Este projeto utiliza como referência visual o Padrão Digital de Governo (https://www.gov.br/ds/home).

## Tokens de Cor (aplicados via Qt Stylesheet)

| Função | Cor | Token GOV.BR |
|--------|-----|-------------|
| Superfície clara | #FFFFFF | Pure 0 |
| Superfície alternativa | #F8F8F8 | Gray 2 |
| Superfície escura (header) | #071D41 | Blue Warm Vivid 90 |
| Texto principal | #333333 | Gray 80 |
| Texto secundário | #636363 | Gray 60 |
| Interativo (primário) | #1351B4 | Blue Warm Vivid 70 |
| Interativo hover | #0C326F | Blue Warm Vivid 80 |
| Interativo claro (fundo) | #D4E5FF | Blue Warm Vivid 10 |
| Sucesso | #168821 | Green Cool Vivid 50 |
| Erro | #E52207 | Red Vivid 50 |
| Alerta | #FFCD07 | Yellow Vivid 20 |
| Info | #155BCB | Blue Warm Vivid 60 |

## Tipografia

- Família: Rawline (GOV.BR), fallback: Roboto, Segoe UI, sans-serif
- Tamanhos: 11px (XS), 12px (SM), 14px (MD), 16px (LG), 20px (XL), 24px (XXL)

## Componentes Qt mapeados

- Botão primário: fundo azul (#1351B4), texto branco, sem borda, radius 4px
- Botão secundário: fundo transparente, borda azul, texto azul
- Botão terciário: sem borda, texto azul
- Input: borda cinza (#CCCCCC), radius 4px, foco com borda azul 2px
- Tabs: sem borda, indicador inferior azul 3px na tab ativa
- ProgressBar: fundo cinza claro, chunk azul interativo
- Cards: borda cinza claro (#E6E6E6), radius 8px
- Header: fundo escuro azul marinho (#071D41), texto branco
